# Plataforma de pedidos de gás e água

Produto para pedidos de gás e água, com operação por centrais, começando pelo piloto de Goiatuba. O repositório é privado e os projetos antigos do GitHub ficam fora do escopo.

## Estado atual

O trabalho está na definição conjunta da arquitetura. Ainda não há código de produto, banco, ambientes ou integrações configurados. Nenhuma função deve ser implementada até as decisões pendentes em `docs/DECISOES.md` serem discutidas e aprovadas.

## Documentação

- `CLAUDE.md`: regras de trabalho e qualidade.
- `docs/ARQUITETURA.md`: requisitos e arquitetura-base.
- `docs/DECISOES.md`: decisões registradas e pontos que precisam de aprovação.
- `docs/PROGRESSO.md`: estado do trabalho e próximo passo.

## Princípios

Segurança e privacidade primeiro; Flutter/Dart para as interfaces; qualidade profissional, código organizado e decisões documentadas. As centrais são dados configuráveis, não cidades fixadas no código.
