# Painel do proprietário

Shell Flutter Web responsivo para o proprietário administrar somente a própria empresa/tenant. As áreas planejadas são Visão geral, Centrais, Produtos, Pedidos e Relatórios.

Os módulos atuais são estados explícitos de preparação: não há autenticação, operações de escrita, dados de demonstração, consultas, métricas ou permissões simuladas. O backend/RLS deverá impor o escopo do tenant antes de qualquer tela receber dados.

A decisão pendente D-006 define se além do painel web haverá aplicativo móvel do proprietário. Este projeto está planejado como web; não publicar antes da revisão de acesso e da definição do ambiente.
